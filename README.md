# জাদুর কাঠি (Jadur Kathi) — Android UI starter

বাংলাদেশি মার্কেটপ্লেসের জন্য Kotlin + Jetpack Compose starter project।

## অন্তর্ভুক্ত UI
- হোম পেজ, সার্চ ও ডেমো পণ্য
- ক্যাটাগরি
- ভিডিও শপিংয়ের প্রিভিউ স্ক্রিন
- কার্ট, অর্ডার
- প্রোফাইল
- বিক্রেতা প্যানেলের নমুনা
- অ্যাডমিন প্যানেলের নমুনা
- অভিযোগ ফর্ম

## Android Studio দিয়ে চালানো
1. Android Studio-তে এই ফোল্ডারটি Open করুন।
2. Gradle sync সম্পন্ন হতে দিন (ইন্টারনেট লাগতে পারে)।
3. Android SDK 35 ইনস্টল/নির্বাচন করুন।
4. Emulator বা USB debugging চালু Android ফোন বেছে Run চাপুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি UI starter/demo, সম্পূর্ণ production app বা APK নয়। পণ্য/অ্যাকাউন্ট/অর্ডার এখন স্থানীয় ডেমো অবস্থায়; ভিডিও আপলোড, লগইন, ডেটাবেস, পেমেন্ট, ডেলিভারি, রিফান্ড, নোটিফিকেশন এবং সার্ভার-সাইড admin permissions এখনো সংযুক্ত নয়। বাস্তব অ্যাডমিন নিরাপত্তা অবশ্যই সার্ভারে যাচাই করতে হবে; শুধু UI-তে লুকিয়ে রাখা যথেষ্ট নয়।
